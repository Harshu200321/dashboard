User Signup and Login System with Role-Based Dashboards
This project implements a simple user authentication system using Django, allowing users to sign up and log in with different roles. The available user roles are:

Patient
Doctor
Features:
User registration with first name, last name, username, email, password, profile picture, and address.
Password and confirm password validation to ensure both fields match.
Login system with redirection to role-based dashboards (Patient or Doctor).
A simple, stylish user interface created with inline CSS for ease of use and responsiveness.
Technologies Used:
Django
HTML
CSS (Inline)
This project demonstrates basic Django authentication and user role handling, providing a solid foundation for more complex systems requiring user management.
